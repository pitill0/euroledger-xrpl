# Telegram Alert Notifications in n8n

EuroLedger XRPL includes an example n8n workflow that sends Alertmanager notifications to Telegram.

## Workflow

```text
automation/n8n/euroledger-alertmanager-telegram.json
```

The workflow contains no Telegram token, credential or real chat ID.

## Create the Telegram Bot

In Telegram:

1. open a chat with `@BotFather`;
2. send `/newbot`;
3. choose a display name and bot username;
4. copy the bot token.

In n8n, create a Telegram credential and paste the token into the **Access Token** field.

n8n's Telegram credential uses the bot token generated by BotFather. The bot must also be added to the target channel or group when messages are sent there.

## Get the Chat ID

For a direct chat:

1. open the bot in Telegram;
2. send it a message;
3. use a Telegram Trigger temporarily in n8n, or inspect the bot updates, to obtain the numeric chat ID.

For a public channel, n8n also accepts a channel username in the form:

```text
@channelusername
```

For groups and private channels, use the numeric chat ID.

## Import and Configure

Import:

```text
automation/n8n/euroledger-alertmanager-telegram.json
```

Then open **Send Telegram Alert** and configure:

1. **Credential to connect with**: select the Telegram credential;
2. **Chat ID**: replace `REPLACE_WITH_TELEGRAM_CHAT_ID`;
3. keep **Resource** as `Message`;
4. keep **Operation** as `Send Message`.

The Telegram node supports sending messages to a chat, group or channel. Telegram messages are limited to 4096 characters after entity parsing.

## Publish the Workflow

The production webhook only works after the workflow is published.

Production URL inside Compose:

```text
http://n8n:5678/webhook/euroledger-alerts
```

Test URLs using `/webhook-test/` only work while n8n is actively listening for a test event.

## Message Format

Firing critical alert:

```text
🚨 🔴 EuroLedger alert

Alert: EuroLedgerBackendDown
Status: firing
Severity: critical
Component: backend
Summary: EuroLedger backend is unavailable
Description: Prometheus has been unable to scrape the backend.
Started: 2026-06-12T10:00:00Z
```

Resolved alert:

```text
✅ 🔴 EuroLedger alert resolved

Alert: EuroLedgerBackendDown
Status: resolved
Severity: critical
Component: backend
Summary: EuroLedger backend is unavailable
Resolved: 2026-06-12T10:05:00Z
```

## Manual Test

After selecting credentials, setting the Chat ID and publishing:

```bash
curl -i   -X POST   http://localhost:5678/webhook/euroledger-alerts   -H 'Content-Type: application/json'   -d '{
    "receiver": "critical-webhook",
    "status": "firing",
    "commonLabels": {
      "alertname": "ManualTelegramTest",
      "severity": "critical",
      "component": "backend"
    },
    "commonAnnotations": {
      "summary": "Manual Telegram notification test",
      "description": "Testing the versioned n8n Telegram workflow."
    },
    "alerts": [
      {
        "status": "firing",
        "labels": {
          "alertname": "ManualTelegramTest",
          "severity": "critical",
          "component": "backend"
        },
        "annotations": {
          "summary": "Manual Telegram notification test"
        }
      }
    ]
  }'
```

The Telegram message should be sent and the execution should appear in n8n.

## End-to-End Test

Stop the backend:

```bash
docker compose stop backend
```

Wait until `EuroLedgerBackendDown` fires. Telegram should receive the firing notification.

Restore the backend:

```bash
docker compose start backend
```

Telegram should later receive the resolved notification because Alertmanager uses `send_resolved: true`.

## Credentials and Security

- Do not commit the Telegram bot token.
- Store credentials only in n8n.
- Do not export credentials with the workflow.
- Restrict who can add the bot to groups or channels.
- Regenerate the token through BotFather if it is exposed.
- Use a dedicated bot for EuroLedger operational alerts.
